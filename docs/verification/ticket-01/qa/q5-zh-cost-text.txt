"LightRAG 和 GraphRAG 的成本差異是什麼？\n\nAnswer complete\n\nLightRAG 的成本遠低於 GraphRAG。  \n\n- **檢索階段**：GraphRAG 需要為 1,399 個社群生成報告，實際使用 610 個二層社群，每個報告約 1,000 個 token，總計約 610,000 個 token，且必須逐一遍歷社群，導致「數百」次 API 呼叫；相較之下，LightRAG 只用不到 100 個 token 產生關鍵字並完成檢索，整個過程僅需一次 API 呼叫[C4]。  \n\n- **增量更新階段**：兩者在實體與關係抽取的初始開銷相似，但 GraphRAG 必須拆除並重新生成整個社群結構。每個社群報告的重建需約 5,000 個 token，對 1,399 個社群而言，重建原始與新資料共需約 1,399 × 2 × 5,000 個 token，成本極高；LightRAG 則直接將新抽取的實體與關係加入現有圖中，無需完整重建，因而「顯著降低」增量更新的開銷[C5]。  \n\n因此，LightRAG 在 token 使用量、API 呼叫次數以及動態資料更新的重建成本上，都比 GraphRAG 更具成本效益。\nTrace · 1 LLM call"
