完整開發紀錄保存於 [歸檔標籤](history.md)；先讀 [精選案例](ai-collaboration.md)。本檔只追加目前主分支的重要新決策與修正。

## 2026-10-14：精簡主分支與縮短程式路徑

- **人改變方向**：前一輪只精簡交付 zip，仍留下繁多歷史檔案；使用者明確要求 repo 本身簡潔，核准 Git 標籤保存歷史、主要程式搬到 `app/`。
- **AI 執行**：自行完成，不呼叫其他 agent。移除過時驗證工具與紀錄；保留最後真實回答／事件／判分、可重跑評估及精選協作證據。
- **主要重構**：上傳處理集中到 ingestion；PDF 版面與 Section 組裝分離；表格定位／格線解讀／文字輸出分離；Router 題庫與劇本模型移出正式套件。
- **驗證修正**：搬移後發現本機 editable 安裝仍指向舊路徑，導致獨立腳本無法 import；以既有鎖檔離線重新安裝修正。PDF 前後比對先統一 JSON 的 tuple/list 表示，再逐欄比較。
- **驗證範圍**：[validation.md](validation.md) 記錄回歸、解析一致性及安裝結果；不把結構重構稱為回答品質提升。

## 2026-10-14：字型分片與驗證產物

- **人調整方向**：要求減少字型檔案，並明確指定驗證產物應放哪裡。
- **AI 修正先前整理的不足**：先前只指出字型分片有用途，未檢查整併可能性；本次以相同版本與既有全部字元，將 108 個分片收斂為單一 Regular，保留授權且減少 18.5% 容量。
- **後續規則**：暫存不提交、必要案例進 tests、精選評估進 eval/results、結論更新同一份 validation；AGENTS 僅連到開發指南的規則，不再建立逐輪驗證目錄。
