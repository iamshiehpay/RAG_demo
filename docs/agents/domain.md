# 領域文件

本專案是單一領域，正式 Python 程式位於 `app/`。

- 探索或修改功能前，讀取根目錄的 [CONTEXT.md](../../CONTEXT.md)，程式、測試與文件沿用其中的術語。
- 修改處理規則時，讀取 [設計規格](../design.md) 的相關章節。
- 修改架構邊界時，讀取相關 [ADR](../adr/)；目前提問編排決策見 [LangGraph ADR](../adr/2026-10-14-langgraph-ask.md)。

若需要的概念不在 CONTEXT 中，先確認是否真的需要新增術語；涉及難以逆轉的決策時新增 ADR。新提案與既有 ADR 衝突時明確指出差異，再依使用者決策更新，避免文件與實作各說各話。
