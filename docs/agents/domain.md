# 領域文件

本專案是單一領域，正式 Python 程式位於 `app/`。

- 探索或修改功能前，沿用 [設計規格](../design.md) 與現有程式中的術語；若本機有 `CONTEXT.md`，一併參考。
- 修改處理規則時，讀取 [設計規格](../design.md) 的相關章節。
- 修改架構邊界時，讀取 [程式導覽](../development.md#程式導覽)；若本機有 `docs/adr/`，再查閱相關決策。

若需要的概念尚未定義，先確認是否真的需要新增術語；涉及難以逆轉的決策時新增 ADR。新提案與既有 ADR 衝突時明確指出差異，再依使用者決策更新，避免文件與實作各說各話。
